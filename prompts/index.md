Installed capability catalog. This index stays stable; it is not a list of what is currently unavailable. Jev prepares matching tool declarations and complete skill instructions automatically. Skills whose full instructions are already present do not need another load or read just to obtain them. If a capability you need is still unavailable, call `load_capabilities` directly as a tool call, never through `codemode`: `tools.load_capabilities` does not exist there. Pass its name, the group name from a `---` line, or a short description of the need. Wait for loading to finish before using newly declared tools. Each entry includes a shortened selection hint, not full instructions. Loading never grants permission to execute a tool or follow a workflow.
